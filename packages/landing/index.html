Agent = Engine + Cockpit
Cockpit

keeps you in command while the agent works

The engine is the brain. The cockpit is where you read, decide and steer. FlupCode rebuilds only the cockpit, on top of the OpenCode engine you already run.

The engine, untouched

FlupCode talks to the same HTTP and SSE API every OpenCode client uses. No new backend, no fork of the agent loop, upstream stays mergeable.

A cockpit you can read

Side-by-side diffs, collapsible reasoning, expandable tool output, a clear turn footer. What the terminal prints, FlupCode lays out.

Controls that mean something

Permission modes, plan versus build, model and effort pickers. The rules live in the engine, so the UI never lies about what the agent may do.

Tour

Everything the terminal does. In a real UI.

Rich chat with real diffs

Every edit shows as a side-by-side diff, every command with its output. Reasoning collapses out of the way; nothing is hidden behind a scrollback.

An embedded terminal

A real PTY in a workspace panel, wired to the engine. Resize it, type in it, run your tests next to the conversation. No context switch.

Home that shows your week

Sessions, messages, tokens, streaks and an activity heatmap across every project. Cost stays one glance away, not one dashboard away.

Permission modes per session

Switch from Manual, where every change is confirmed, to Bypass for unattended runs. The chip in the composer always tells the truth.
