# Contributing to FlupCode

Thanks for helping. FlupCode's contribution guide lives in
[docs/CONTRIBUTING.md](docs/CONTRIBUTING.md): getting started, conventions, testing, and how we
push, merge and deploy.

FlupCode runs on the official [OpenCode](https://github.com/anomalyco/opencode) 2 engine at a pinned
version (see [docs/UPSTREAM.md](docs/UPSTREAM.md)); changes to the engine itself belong in OpenCode's
repository.
