# Contributing to FlupCode

Thanks for helping. FlupCode's contribution guide lives in
[docs/CONTRIBUTING.md](docs/CONTRIBUTING.md): getting started, conventions, testing, and how we
push, merge and deploy.

FlupCode is built on [OpenCode](https://github.com/anomalyco/opencode). The engine packages under
`packages/` come from upstream and are not edited here (see [docs/UPSTREAM.md](docs/UPSTREAM.md));
changes to the engine itself belong in OpenCode's repository.
